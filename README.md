\# Phishing Email Detector (DevSecOps Project)



\## Overview

This project is a phishing email detection system developed using DevSecOps principles. It integrates security across design, development, testing, deployment, and monitoring stages.



\## Features

\- Secure authentication with RBAC and 2FA

\- Email phishing detection using heuristics

\- Email quarantine

\- Risk-based indicators

\- CI/CD pipeline with security testing



\## Technology Stack

\- Python (Flask)

\- SQLite

\- GitHub Actions

\- Bandit, pip-audit, OWASP ZAP



\## Repository Structure

/src      - Application source code

/docs     - Documentation

/tests    - Test files

/ci-cd    - CI/CD pipeline configuration
