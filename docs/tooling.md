# Tool Selection Justification

## GitHub Actions
GitHub Actions was selected to automate build, test, and security checks within the CI/CD pipeline due to its native integration with GitHub repositories and support for DevSecOps workflows.

## Bandit
Bandit was chosen as a Static Application Security Testing (SAST) tool to identify common security issues in Python code during development.

## pip-audit
pip-audit is used to detect known vulnerabilities in third-party Python dependencies, supporting secure dependency management.

## OWASP ZAP
OWASP ZAP was selected as a Dynamic Application Security Testing (DAST) tool to identify runtime vulnerabilities such as injection flaws and misconfigurations.

These tools collectively support continuous security testing across the development lifecycle.
